# Team Mohawk Sponsorship Landing Page

A responsive, business-facing sponsorship landing page built from the supplied Mohawk photography.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive premium combat-sports styling
- `script.js` — smooth navigation, package calculator, inquiry form
- `assets/` — supplied photography

## Before publishing
1. Replace the `mailto:` form destination with the actual Team Mohawk business email or CRM endpoint.
2. Verify the 6M+ international views and 2M+ BKFC social audience figures.
3. Verify any championship / knockout claims and legal wording.
4. Add real sponsor logos only when authorized.
5. Connect analytics and a production form handler.

The fight-shorts section uses the supplied Team Mohawk placement artwork showing the six available front-of-shorts positions.
